# Beauty-info-flask
 **Описание**:  

Сайт-портал, содержащий все салоны красоты города Гродно.

 **Как запустить проект?**: 
 
  Установить все зависимости
  
 ```
 pip install -r requirements.txt
```

и прописать команду:
 ```
python app.py
```
Далее перейти по локальному адресу. В Flask это обычно http://localhost:8000 или http://127.0.0.1:8000. 

Есть на хостинге: https://beauty-info-flask.onrender.com
